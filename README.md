# Cloud Infrastructure Deployment on Google Cloud Platform

This repository documents the end-to-end provisioning and configuration of a cloud-hosted virtual machine on Google Cloud Platform, deployed as a fully functional remote working and development environment.

Executed within a live cloud environment utilizing trial credits, the project features an e2-medium Ubuntu instance configured with Virtual Private Cloud networking, firewall rules for secure ingress traffic, and an XFCE desktop environment accessible remotely via the Remote Desktop Protocol. The infrastructure successfully hosts both a containerized workflow automation platform using Docker and the N8N community edition, alongside an AI-assisted development environment utilizing the Antigravity IDE. 

This project demonstrates advanced multidisciplinary skills spanning cloud infrastructure engineering, Linux systems administration, DevOps containerization, and real-world troubleshooting of zone availability and networking challenges.
